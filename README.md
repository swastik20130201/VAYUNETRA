# ⚡ VAYUNETRA | atmospheric intelligence system

**VAYUNETRA** (Sanskrit for *"Atmospheric Eye"*) is a high-performance web dashboard delivering real-time weather analytics, air quality indexing (AQI), global synoptic visualizations, and breaking environmental intelligence.

---

## ✨ Features

* **Real-Time Weather Metrics:** Temperature, feels-like readings, humidity, atmospheric pressure, wind vectors, and UV index.
* **Air Quality Command Centre:** Detailed breakdown of PM2.5, PM10, Ozone ($O_3$), and Nitrogen Dioxide ($NO_2$).
* **24-Hour Timeline & 10-Day Trends:** Granular hourly forecasts and extended atmospheric trends.
* **Global Synoptic View:** Embedded 3D globe visualization powered by `earth.nullschool.net` for tracking planetary wind vectors and ocean currents.
* **Solar Cycle Tracking:** Real-time daylight calculation with dynamic sunrise/sunset trajectory visualizers.
* **Environmental News Feed:** Live science and climate updates integrated directly from global news sources.
* **VayuAI Assistant:** An integrated, interactive conversational agent designed to help users query weather and climate data.

---

## 🛠️ Data Sources & Technologies

* **Atmospheric Data:** Open-Meteo, ECMWF, GFS
* **Global Visualizations:** Earth Nullschool API
* **News Intelligence:** BBC News (Science & Environment)
