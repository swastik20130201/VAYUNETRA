# VAYUNETRA
**Vayunetra** is a real-time weather and atmospheric intelligence dashboard. Monitoring Ghaziabad, Uttar Pradesh, it tracks live metrics—31°C (feels like 39°C), 76% humidity, Very Poor AQI (83), and 2 km/h NE winds. It features 24-hour forecasts, 10-day trends, pollutant tracking, a 3D Earth wind simulation, and integrated BBC climate news.
